# Practical 03: Performing Basic Branching and Merging in Git

## 1. Aim
To create branches, make changes, and merge branches in Git.

## 2. Requirements
- Git
- GitHub
- VS Code
- Internet Connection

## 3. Theory
Branching allows developers to work on separate features without affecting the main branch. Merging combines changes from one branch into another branch.

## 4. Procedure
Step 1: Check the repository status.
Step 2: Create a new branch.
Step 3: Switch to the feature branch.
Step 4: Create and modify a file.
Step 5: Add and commit the changes.
Step 6: Switch back to the main branch.
Step 7: Merge the feature branch into main.
Step 8: Push changes to GitHub.

## 5. Commands

- `git status` – Check repository status.
- `git branch feature-branch` – Create a new branch.
- `git checkout feature-branch` – Switch to the feature branch.
- `git add feature.txt` – Stage the file.
- `git commit -m "Add feature file"` – Commit changes.
- `git checkout main` – Switch to main.
- `git merge feature-branch` – Merge branches.
- `git push origin main` – Upload changes to GitHub.
- `git log --oneline` – View commit history.

## 6. Result
Successfully created a feature branch, committed changes, merged it into the main branch, and pushed the changes to GitHub.
